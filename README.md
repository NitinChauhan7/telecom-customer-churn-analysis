# Telecom Customer Churn Analysis

## 📌 Project Overview
This project analyzes customer churn in the telecom industry using Python, data analysis, and data visualization.

The main objective is to identify the key factors that influence customer churn and provide useful business insights to help reduce customer loss.

## 📊 Dataset
- Total Records: 7,043 customers
- Total Features: 21
- Target Variable: Churn
- Churned Customers: 1,869
- Overall Churn Rate: 26.54%

## 🔍 Key Findings
- Month-to-month contract customers have the highest churn rate.
- Customers with higher monthly charges show higher churn.
- Customers without Online Security and Tech Support show higher churn.
- Electronic Check is one of the major payment methods among churned customers.
- Fiber optic internet customers show relatively higher churn.

## 💡 Business Recommendations
- Encourage customers to move from month-to-month contracts to longer-term plans.
- Provide targeted retention offers to high-risk customers.
- Improve customer support and technical assistance.
- Promote value-added services such as Online Security and Tech Support.
- Monitor customers with high monthly charges.
